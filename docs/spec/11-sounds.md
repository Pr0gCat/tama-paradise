來源：`re/decomp-all/XIP.c` 全部呼叫點，由 `docs/spec/tools/sfx_map.py` 產生 `data/sound_usage.csv`（每列：音效、函式、播放方式、所屬場景）。

- 播放函式：`snd_play` 0x10024c60、`snd_play_vol` 0x10024c78（`FUN_10023f20` 檢查 id < 0x57 後呼叫）、循環 `snd_play_loop` 0x10024e08（`FUN_10023f54`）、`snd_play_div` 0x10024e30、`snd_play_div_loop` 0x10024f80（`FUN_10024f60(id, 次數)` = 背景音樂）、`FUN_100027a0(frames, id)` = 等待逾時時播 id。另外 motion script 的 op 0x0e（`sound A=id`）。
- 場景歸屬：從場景表的 init/update/draw/exit 往下追呼叫圖（深度 ≤ 6），取最近的場景；共用函式會列出多個場景。表格查用的音效（`0x1009390e` playdate、`0x100a13b8` 細胞、`0x10095768/70` lab 03/04 結果）另列於下。
